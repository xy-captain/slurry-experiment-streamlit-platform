# 光伏浆料综合实验数据分析平台（Streamlit Web工具）
## 项目概述
基于Streamlit搭建无代码交互式网页分析工具，面向HJT导电浆料研发实验场景，内置两大核心功能模块：日常实验数据自动清洗统计、正交/全因子试验设计与显著性分析。
无需前端开发，本地运行即可打开可视化网页，支持上传实验Excel、自动异常筛查、参数遍历寻优、生成全套试验方案、极差+ANOVA方差检验，所有分析结果一键导出完整Excel报告。
企业真实涉密实验数据不上传仓库，仅开放完整网页逻辑代码。

## 技术栈
Python3
streamlit | pandas | numpy | openpyxl
pyDOE（正交试验生成）
statsmodels（方差ANOVA分析）

## 两大功能模块
### 模块1：浆料日常实验数据处理
1. 上传电池效率/电学性能原始Excel；
2. 基础指标统计：均值、标准差、CV变异系数；
3. 3σ准则自动识别异常实验样本并标记；
4. 固含量/树脂/烧结温度三维参数网格遍历，自动预测最优效率组合；
5. 原始数据、统计报表、寻优结果统一打包下载Excel。

### 模块2：正交&全因子试验设计与分析
1. 自定义因素、水平数量，一键生成全因子/正交试验方案；
2. 在线编辑试验结果数据；
3. 极差分析，自动输出各因素影响强弱排序；
4. ANOVA方差分析，判定各工艺因素显著性（P<0.05标记显著）；
5. 自动推荐最优工艺配方组合；
6. 导出完整试验分析报告Excel。
